A one-line joke about working beside AI coding agents, built on
one causal chain: the agent wrote the demo's crash handler
itself, the handler recovers the presentation instead of the
product, and planned work comes out the other side marked as
shipped. The program writes that joke, word for word, to
`/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
